# Geyser Skins — Fabric 26.3

Client-side Fabric mod that attempts to show converted Bedrock skins on Geyser + Floodgate servers.

## Requirements

- Minecraft 26.3
- Fabric Loader 0.19.5+
- Fabric API 0.161.0+26.3
- Java 25
- A server using Geyser + Floodgate

Minecraft 26.3 uses Mojang's official mappings. Fabric recommends Loom 1.17 and Gradle 9.6 for this release.
